Yu GAS プライバシーポリシー

このページは、「Yu GAS」の名前で動く Google Apps Script のツール（以下「本ツール」）が、どの情報をどう扱うかを示します。 本ツールは運営者本人が使うためのもので、Google アカウントの権限を許可するのは運営者本人だけです。

1. 使う情報

  • 運営者本人の Google カレンダー：予定の表示・追加・変更・削除、空き時間の確認、時間の配分の集計に使います。
  • 運営者本人の名前でのメール送信：予約の確認・変更・取り消し・前日のお知らせを、予約された方へ送るために使います。
  • 日程調整で予約される方の情報（お名前・メールアドレス・会社名・ご記入のメモ）：予約の予定を作り、知らせを送るためだけに使います。

2. 保存と削除

予約の控えは、本ツールのスクリプトの保存場所（Google のスクリプト プロパティ）に置きます。 終わった予約は 90 日後、取り消された予約は 7 日後に自動で消します。予約の予定は、運営者の Google カレンダーに残ります。

3. 第三者への提供

集めた情報を第三者に渡したり、売ったりしません。広告や分析には使いません。

4. Google の API から得た情報

Google の API から得た情報の使い方と他のアプリへの受け渡しは、 Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 予約された方の情報の削除

予約の確認メールにある変更・キャンセル用の URL から、いつでも予約を取り消せます。控えの削除を希望される場合は、確認メールに返信してお知らせください。

6. 問い合わせ

本ツールについての問い合わせは、予約の確認メールへの返信、または Google の同意画面に表示されるサポート用のメールアドレスへお送りください。
